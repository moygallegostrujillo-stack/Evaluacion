# A-06.6 — 05 · Calidad de Preguntas (PASO 4)

## 1. Regla

Medir conceptualmente: claridad, especificidad, conducta pasada, relevancia, capacidad de producir evidencia, riesgo de respuesta socialmente deseable, riesgo de interpretación múltiple. Clasificar: STRONG / ACCEPTABLE / NEEDS_REVISION / REJECT.

## 2. Criterios por dimensión

| Dimensión | Cómo se mide |
|---|---|
| Claridad | ¿El candidato entiende qué se le pide? (verificado en casos sintéticos M-G/V-G con probes) |
| Especificidad | ¿Pide un evento específico (no generalidades)? |
| Conducta pasada | ¿Pide qué hizo (no qué haría)? |
| Relevancia | ¿Mapea a competencia + indicador + puesto? |
| Capacidad de producir evidencia | ¿Produce Action observable en los casos simulados? |
| Riesgo de respuesta socialmente deseable | ¿Un candidato puede "adivinar" la respuesta deseable? |
| Riesgo de interpretación múltiple | ¿La pregunta puede interpretarse de varias formas ambiguas? |
