# EVALUHR — A-06.7 — 07 · Reglas de Respuestas Hipotéticas (PASO 7)

> **PILOTO / DRAFT / NO PRODUCTIVO.** Formalización: "¿Qué harías?" **no es evidencia conductual**.
> HYPOTHETICAL → **LIMITED como máximo**. Nunca SUPPORTED. Nunca STRONG.

## 1. Principio

La entrevista BDI busca conducta **pasada y real**. La respuesta hipotética describe **intención futura**
("haría X") o una generalidad condicional ("cuando pasa X, hago Y"). La intención puede ser sincera y
bien razonada, pero **no demuestra que el candidato haya hecho nunca eso** — y por tanto no acredita
competencia demostrada. Regla del piloto: M-C y V-C (HYPOTHETICAL → LIMITED, no escaló).

## 2. Reglas formales

| # | Regla |
|---|---|
| **H-1** | Respuesta hipotética pura ("¿Qué harías si…?" respondida en futuro) → categoría HYPOTHETICAL → estado **LIMITED** como máximo. |
| **H-2** | HYPOTHETICAL **nunca** alcanza SUPPORTED ni STRONG, ni con juicio excelente, ni con "buen criterio", ni con resultados proyectados. |
| **H-3** | Condicional general ("cuando un cliente se enoja, yo lo calmo") = patrón GENERAL_CLAIM → **INSUFFICIENT**, salvo que ancle instancias pasadas específicas (→ evaluar esas instancias como CONCRETE_BEHAVIOR). |
| **H-4** | Redirección: ante hipotético, aplicar PROBE-UNI-005 ("¿Puedes darme un ejemplo específico de una vez que…?"), máx 2 redirecciones. |
| **H-5** | **Si la redirección produce un ejemplo pasado real, ese ejemplo se evalúa por sí mismo** (puede llegar a SUPPORTED/STRONG por sus propios méritos). El hipotético no "contamina" el ejemplo real, pero tampoco suma a él. Estados por unidad de evidencia, no mezclados. |
| **H-6** | Si tras 2 redirecciones no hay ejemplo pasado → el nivel queda LIMITED (hipotético) o INSUFFICIENT (solo opinión/generalidad); para entry-level sin experiencia → NO_EVIDENCE legítimo + nota de complemento situacional. |

## 3. Ejemplos de calibración

### 3.1 Hipotético puro → LIMITED (patrón M-C/V-C)

> "Si un comensal se quejara, lo escucharía con calma y le ofrecería una solución."

- Categoría: HYPOTHETICAL → **LIMITED** (no SUPPORTED). Error común que la rúbrica v2 bloquea: "sabe qué hacer → SUPPORTED". Saber qué hacer ≠ haberlo hecho.

### 3.2 Hipotético elicitido por la propia pregunta (CAL-23, VENDEDOR, Q-VEN-SVC-002)

> Entrevistador: "Describe una ocasión en que un cliente presentó un reclamo difícil." — Candidato: "No sé… supongo que si un cliente me reclamara, primero lo calmaría y luego le buscaría solución."

- Categoría: HYPOTHETICAL → **LIMITED**. La respuesta reformuló la pregunta BDI como situacional. Redirección PROBE-UNI-005 → "¿Puedes contarme una vez real, aunque fuera pequeña?"; si no hay → se queda LIMITED y se documenta.

### 3.3 Condicional general → INSUFFICIENT, salvo anclaje pasado

> "Cuando se cae el sistema, yo mantengo la calma y sigo vendiendo con la terminal offline."

- Sin anclaje: patrón GENERAL_CLAIM → **INSUFFICIENT** (no LIMITED: no describe ni siquiera una escena concreta).
- Con anclaje tras redirección ("la semana pasada se cayó el sistema y yo…") → evaluar el ejemplo pasado: puede alcanzar SUPPORTED por sus propios méritos (regla H-5).

### 3.4 Redirección exitosa → el ejemplo real se evalúa solo

> "Si me tocara un cliente furioso, lo escuchara…" → PROBE-UNI-005 → "Bueno, la otra semana una clienta quería devolver un vestido sin ticket y yo le ofrecí cambio con vale…"

- El hipotético inicial: se ignora para el nivel (no suma). El ejemplo real: CONCRETE_BEHAVIOR → evaluar indicadores + R → puede llegar a SUPPORTED.

## 4. Qué NO hace la regla

- **No castiga**: LIMITED no es "malo" ni 0; es evidencia parcial de menor calidad (INSUFFICIENT ≠ 0 se mantiene).
- **No elimina al candidato**: entry-level puede responder hipotéticamente por falta de experiencia → NO_EVIDENCE + complemento situacional (A-06.3), no veto.
- **No autoriza a discutir**: el entrevistador no debate el contenido del hipotético; solo redirige (máx 2) y documenta.
- **No cambia con IA**: la IA no reclasifica un hipotético como conducta (ver `12-ai-boundaries.md`, rechazo 1).
