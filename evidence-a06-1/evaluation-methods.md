# A-06.1 — Evaluation Methods (PASO 6)

## 2. Análisis por método

### A. Entrevista estructurada

**Qué mide**: comportamientos pasados (BDI — Behavior Description Interview) o intenciones frente a situaciones (situacional). Estructura: mismas preguntas a todos los candidatos, escala de evaluación definida, múltiples entrevistadores.

**Evidencia**:
- Huffcutt & Arthur (2001) — meta-análisis, structured interviews predicen desempeño (cited 139+).
- Oliphant (2008) — predictive validity confirmada para behavioral interviews (cited 21).
- Hartwell (2019) — 4 tipos comparados: past behavioral, situational, background, job knowledge; past behavioral más fuerte.
- Huffcutt et al. (2003) — behavior description > situational para validez.

**Ventajas**: validez establecida; flexible por puesto; evidencia conductual; bajo costo de implementación.

**Limitaciones**: sesgo de entrevistador (halo, similaridad); faking posible; requiere entrenamiento de entrevistadores; consistencia inter-evaluador es un reto.

**Costo**: BAJO-MEDIO (entrenamiento + guía; no requiere instrumento propietario).

**Implementación**: VIABLE para V1 — es el método base del modelo recomendado (ver PASO 17).

### B. Entrevista conductual (STAR/BDI)

**Qué mide**: comportamientos pasados específicos vía técnica STAR (Situation, Task, Action, Result).

**Evidencia**: Pulakos & Schmitt (1995) — BD > situational para posiciones de mayor nivel.

**Ventajas**: evidencia concreta; menos faking que auto-reporte (pasado verificable).

**Limitaciones**: requiere entrevistador hábil; tiempo por candidato; codificación subjetiva.

**Implementación**: VIABLE — es un sub-tipo de la entrevista estructurada.

### C. BEI (Behavioral Event Interview)

**Qué mide**: eventos críticos que diferencian desempeño superior de promedio (McClelland 1976; Spencer & Spencer 1993).

**Evidencia**: ESTABLISHED para identificación de competencias (no para evaluación de candidatos individuales — requiere muestra de estudio).

**Ventajas**: profundidad; base científica sólida.

**Limitaciones**: MUY costoso (2–3 horas por entrevista + codificación); requiere codificadores entrenados; hecho para construir el modelo, no para evaluar a cada candidato.

**Implementación**: NO V1 — recurso-intensivo. Útil post-V1 para refinar el catálogo de competencias.

### D. SJT (Situational Judgment Test)

**Qué mide**: juicio del candidato frente a escenarios laborales (selección de respuesta).

**Evidencia**:
- McDaniel et al. (2001) — meta-análisis r≈.34 para desempeño (cited 595).
- Christian (2010) — constructs, reliability, validity (cited 595).
- Whetzel (2009) — overview (cited 379).
- Webster (2020) — r≈.32 en campo médico.

**Ventajas**: estandarizado; escalable; menor impacto adverso que tests cognitivos.

**Limitaciones**: construcción costosa (escenarios válidos); faking posible; validez de constructo compleja (mide mezcla de cognición + personalidad + experiencia); requiere baremos.

**Costo**: MEDIO-ALTO (desarrollo del item set).

**Implementación**: POSIBLE post-V1 — requiere desarrollo del item set específico por sector (e.g. mesero, cajero).

### E. Cuestionario (auto-reporte)

**Qué mide**: auto-percepción de comportamiento.

**Limitaciones**: faking ALTO (candidato motiva respuesta deseable); no produce evidencia conductual; validez para decisión individual LIMITADA.

**Implementación**: NO como fuente principal. Puede complementar (con advertencia explícita de orientativo).

### F. Assessment Center

**Qué mide**: múltiples dimensiones vía ejercicios simulados.

**Evidencia**: ESTABLISHED (Gaugler et al. 1987; International Task Force on Assessment Center Guidelines 2000).

**Limitaciones**: MUY costoso; logística compleja; tiempo. No viable para V1 de un SaaS multi-tenant mexicano.

### G. Evidencia documental

**Qué mide**: CV, certificaciones, referencias — evidencia indirecta de competencia.

**Papel**: COMPLEMENTO — no fuente principal. Verificable pero no conductual.

## 3. Resumen de recomendación (preview PASO 17)

La combinación recomendada para V1:
- **Fuente principal**: A (entrevista estructurada) + B (conductual STAR).
- **Complemento**: G (evidencia documental).
- **Post-V1**: D (SJT) cuando haya presupuesto de desarrollo.

Esto se ratifica en el modelo recomendado (PASO 17).
