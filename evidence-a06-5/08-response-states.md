# A-06.5 — 08 · Estados de Respuesta (PASO 8)

## 1. Categorías conceptuales

Se definen 7 categorías conceptuales de respuesta. **No asignar puntos.**

| Categoría | Descripción | Ejemplo |
|---|---|---|
| CONCRETE_BEHAVIOR | El candidato describe una conducta específica realizada en una situación pasada | "Me disculpé, le expliqué que llevaría el plato a cocina, le pregunté si quería pan" |
| HYPOTHETICAL | El candidato describe qué haría (intención futura), no qué hizo | "Si tuviera un cliente enojado, lo escucharía con calma" |
| GENERAL_CLAIM | El candidato hace una afirmación general sobre sí mismo | "Soy excelente atendiendo clientes" |
| OPINION | El candidato expresa una opinión sobre el tema | "Creo que el servicio al cliente es fundamental" |
| EXTERNAL_RESULT | El candidato menciona un resultado sin describir su Action | "Aumenté las ventas 50% en mi puesto" |
| NO_INFORMATION | El candidato no aporta ningún ejemplo o no responde | "Nunca he tenido un cliente enojado" (en mesero con experiencia) |
| CONTRADICTION | El candidato dice X en una pregunta y no-X en otra, o contradice el CV | CV dice "lideré 15 personas"; entrevista no describe conducta de liderazgo |

## 2. Mapeo a estados de evidencia (PASO 9)

| Categoría | Estado resultante | Nivel típico |
|---|---|---|
| CONCRETE_BEHAVIOR | VALID | LIMITED / SUPPORTED / STRONG (según nº de indicadores y ejemplos) |
| HYPOTHETICAL | LIMITED (no VALID) | LIMITED (no SUPPORTED sin conducta pasada) |
| GENERAL_CLAIM | INSUFFICIENT | INSUFFICIENT |
| OPINION | INSUFFICIENT | INSUFFICIENT |
| EXTERNAL_RESULT | PENDING_REVIEW | PENDING_REVIEW (hasta verificar Action o referencia) |
| NO_INFORMATION | INSUFFICIENT o NO_EVIDENCE | NO_EVIDENCE (ausencia total) / INSUFFICIENT |
| CONTRADICTION | PENDING_REVIEW | PENDING_REVIEW (conflicto; revisión humana) |

## 3. Estados de evidencia

| Estado | Significado |
|---|---|
| VALID | Evidencia clara, relevante, verificable; múltiples indicadores |
| LIMITED | Evidencia parcial; uno o dos indicadores; o hipotético con juicio razonable |
| INSUFFICIENT | Evidencia presentada pero no aprovechable (vaga, opinión, sin conducta) |
| PENDING_REVIEW | Conflicto entre fuentes; requiere revisión humana |
| INVALID | Evidencia obtenida inválidamente (procedimiento incorrecto, sesgo documentado) |

## 4. Regla: INSUFFICIENT ≠ 0

> **INSUFFICIENT ≠ 0.**

- INSUFFICIENT es una etiqueta cualitativa, no un número.
- No se convierte en 0.
- No se promedia.
- No alimenta decisiones globales automáticamente.
- La competencia queda excluida de agregación automática (regla A-04.5/A-05.3 governance).

## 5. Ejemplos — EJEMPLO — NO PRODUCTIVO

### CONCRETE_BEHAVIOR → VALID

> **EJEMPLO — NO PRODUCTIVO**
>
> "Trabajaba como mesero, un viernes a las 8pm. Un comensal reclamó que su pasta estaba fría. Me disculpé, le expliqué que llevaría el plato a cocina, le pregunté si quería pan mientras esperaba. Coordiné con cocina. Al regresar, le confirmé la temperatura. El cliente aceptó, dejó 15% de propina, sin reclamo posterior."
>
> Categoría: CONCRETE_BEHAVIOR → Estado: VALID → Nivel: SUPPORTED.

### HYPOTHETICAL → LIMITED

> **EJEMPLO — NO PRODUCTIVO**
>
> "Si tuviera un cliente insatisfecho, lo escucharía con calma, le pediría disculpas y le ofrecería una solución."
>
> Categoría: HYPOTHETICAL → Estado: LIMITED (no VALID) → Nivel: LIMITED.

### GENERAL_CLAIM → INSUFFICIENT

> **EJEMPLO — NO PRODUCTIVO**
>
> "Siempre trato bien a los clientes, les doy buen servicio."
>
> Categoría: GENERAL_CLAIM → Estado: INSUFFICIENT → Nivel: INSUFFICIENT.

### EXTERNAL_RESULT → PENDING_REVIEW

> **EJEMPLO — NO PRODUCTIVO**
>
> "Aumenté las ventas 50% en mi puesto anterior."
>
> Categoría: EXTERNAL_RESULT (sin Action) → Estado: PENDING_REVIEW (hasta verificar cómo).

## 6. Conexión con gates

Los estados de respuesta pasan INTERVIEW-G4 (question quality) + INTERVIEW-G8 (human review). Sin categorías definidas + mapeo a estados, la entrevista no es productiva.
