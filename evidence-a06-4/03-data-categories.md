# A-06.4 — 03 · Categorías de Datos (PASO 3)

## 1. Clasificación

Se clasifican 7 categorías de datos que la entrevista podría recopilar. Para cada categoría:
PERMITIDO / CONDICIONAL / NO RECOMENDADO / PROHIBIDO · REQUIERE REVISIÓN LEGAL.

## 2. Matriz

### A. Información profesional

| Campo | Valor |
|---|---|
| ejemplo | trayectoria laboral, puesto anterior, logros |
| clasificación | **PERMITIDO** |
| condiciones | relevante para la competencia evaluada; verificable |
| base jurídica | LFPDPPP Art 6 (finalidad); Art 7 (consentimiento tácito para datos no sensibles) |
| nota | la entrevista BDI pide "ejemplos de situaciones laborales pasadas" → entra aquí |

### B. Experiencia laboral

| Campo | Valor |
|---|---|
| ejemplo | "cuéntame de una vez que atendiste a un cliente" |
| clasificación | **PERMITIDO** |
| condiciones | conducta pasada específica (no años genéricos); STAR completo |
| base jurídica | LFPDPPP Art 6 (finalidad: evaluación de competencias) |
| nota | los "años de experiencia" por sí solos no demuestran competencia (A-06.3 `07-evidence.md`) |

### C. Formación

| Campo | Valor |
|---|---|
| ejemplo | certificaciones, cursos relevantes al puesto (e.g. manipulación de alimentos NOM-251) |
| clasificación | **PERMITIDO** |
| condiciones | solo si es relevante para el puesto (BFOQ o requerimiento del puesto) |
| base jurídica | LFPDPPP Art 6; LFT (requisitos del puesto) |
| nota | no recoger certificaciones irrelevantes al puesto (proporcionalidad) |

### D. Ejemplos conductuales

| Campo | Valor |
|---|---|
| ejemplo | narración STAR de un evento laboral pasado |
| clasificación | **PERMITIDO** (es el núcleo de BDI) |
| condiciones | conducta observable, no opinión; mapeable a indicadores; contexto laboral |
| base jurídica | LFPDPPP Art 6 (finalidad directa) |
| nota | la evidencia principal; ver A-06.3 `03-star.md` |

### E. Referencias laborales

| Campo | Valor |
|---|---|
| ejemplo | contacto del empleador anterior para verificar |
| clasificación | **CONDICIONAL** |
| condiciones | consentimiento del candidato para contactar referencias; verificación de fuente |
| base jurídica | LFPDPPP Art 7 (consentimiento); Art 37 (transferencia a tercero) |
| nota | requiere consentimiento separado para contactar al ex-empleador; el ex-empleador también tiene obligaciones LFPDPPP |

### F. Información personal (no sensible)

| Campo | Valor |
|---|---|
| ejemplo | nombre, contacto, disponibilidad para turno |
| clasificación | **CONDICIONAL** |
| condiciones | solo lo necesario para el proceso de selección; disponible si es BFOQ (e.g. turno requerido) |
| base jurídica | LFPDPPP Art 6, 7 |
| nota | NO recoger domicilio (salvo verificación logística justificada), NO situación familiar, NO aficiones |

### G. Datos sensibles

| Campo | Valor |
|---|---|
| ejemplo | edad, género, embarazo, religión, estado civil, orientación sexual, identidad de género, discapacidad, salud, información genética, origen étnico, opinión política, afiliaciones |
| clasificación | **PROHIBIDO · REQUIERE REVISIÓN LEGAL** |
| condiciones | NUNCA recoger en entrevista de competencias, salvo BFOQ estricto (revisar `14-bfoq.md`) |
| base jurídica | LFPDPPP (definición de datos sensibles — Art 3; consentimiento expreso Art 7); LFT Art 3 (no discriminación); LFPEPD; Constitución Art 1 |
| nota | si el candidato voluntariamente revela un dato sensible (e.g. en una narración STAR menciona su familia), EvaluHR debe NO registrarlo como evidencia; tratar como ruido; no usar para decisión |

## 3. Regla de minimización

> **Recoger lo mínimo necesario.** Si una categoría no aporta evidencia conductual relevante para la competencia, no se recoge.

La entrevista BDI está diseñada para recoger **categoría D (ejemplos conductuales)**. Las categorías A, B, C son complementarias (contexto de los ejemplos). La categoría E (referencias) es una verificación opcional. La categoría F (personal no sensible) se minimiza. La categoría G (sensible) se prohíbe.

## 4. Tabla resumen

| Categoría | Clasificación | ¿Recoger en BDI? |
|---|---|---|
| A. Profesional | PERMITIDO | SÍ (contexto) |
| B. Experiencia | PERMITIDO | SÍ (STAR) |
| C. Formación | PERMITIDO | SÍ (si relevante) |
| D. Conductual | PERMITIDO | SÍ (núcleo) |
| E. Referencias | CONDICIONAL | SÍ (con consentimiento separado) |
| F. Personal no sensible | CONDICIONAL | MÍNIMO |
| G. Sensible | PROHIBIDO | NO |

## 5. Conexión con gates

La clasificación pasa LEGAL-G3 (datos personales) + LEGAL-G4 (datos sensibles). Sin clasificación documentada + prohibición de datos sensibles, la entrevista no se activa.
