# A-06.4 — 19 · Responsabilidades Empresa Cliente vs EvaluHR (PASO 19)

## 1. Regla

Separar obligaciones entre EMPRESA CLIENTE y EVALUHR. **No cambiar la clasificación contractual existente.** Solo auditarla.

## 2. Matriz de responsabilidades

| Actividad | Empresa cliente | EvaluHR | Shared | Base jurídica / razón |
|---|---|---|---|---|
| Determinar la finalidad del proceso de selección | ✓ Responsable | ✗ | ✗ | La empresa cliente decide para qué puesto contrata |
| Definir el puesto (tareas, requisitos) | ✓ Responsable | ✗ | ✗ | Análisis de puesto por la empresa |
| Aprobar criterios (competencias, indicadores) | ✓ Responsable | ✓ Asiste (sugiere) | ✓ | JobCompetency approvedBy: humano de la empresa; EvaluHR puede sugerir |
| Decidir contratación | ✓ Responsable | ✗ | ✗ | Decisión humana de RR.HH. de la empresa |
| Revisar evidencia | ✓ (RR.HH.) | ✓ (reviewer) | ✓ | Ambos pueden revisar; segregación recomendada |
| Conducir la entrevista | ✗ | ✓ Encargado | ✗ | EvaluHR opera la herramienta |
| Conservar evidencia (entrevista, STAR, CompetencyResult) | ✗ | ✓ Encargado | ✗ | EvaluHR como encargado del tratamiento |
| Atender derechos ARCO del candidato | ✗ | ✓ Canal | ✓ | EvaluHR facilita; empresa cliente responde como responsable |
| Administrar la plataforma | ✗ | ✓ Encargado | ✗ | Infraestructura técnica de EvaluHR |
| Aviso de privacidad | ✓ Responsable principal | ✓ Asiste | ✗ | La empresa cliente es responsable; EvaluHR provee texto |
| Consentimiento del candidato | ✓ Responsable | ✓ Facilita | ✗ | La empresa obtiene consentimiento; EvaluHR provee formato |
| Sub-encargados (cloud) | ✗ | ✓ Encargado | ✗ | EvaluHR contrata y gestiona cloud |
| Seguridad técnica | ✗ | ✓ Encargado | ✗ | EvaluHR implementa medidas técnicas |
| Seguridad organizativa (formación entrevistador) | ✓ (si entrevista la empresa) | ✓ (si entrevista EvaluHR) | ✓ | Quien entrevista forma a sus entrevistadores |
| Auditoría de cumplimiento | ✓ Derecho a auditar | ✓ Sujeto a auditoría | ✗ | La empresa puede auditar a EvaluHR |
| Notificación de brechas | ✓ Recibe notificación | ✓ Notifica | ✗ | EvaluHR notifica a la empresa; empresa notifica al INAI |
| Gestión de BFOQ | ✓ Decide + documenta | ✓ Implementa | ✗ | La empresa justifica BFOQ; EvaluHR lo respeta |
| Resolución de conflictos (CV vs entrevista) | ✓ Decisión final | ✓ Sugiere | ✗ | Reviewer humano decide; empresa cliente aprueba |

## 3. Clasificación contractual (auditoría, no cambio)

| Rol LFPDPPP | Quién |
|---|---|
| Responsable del tratamiento | Empresa cliente (define finalidad, decide contratación) |
| Encargado del tratamiento | EvaluHR (opera la plataforma, conduce entrevistas, conserva evidencia) |
| Sub-encargado | Proveedor cloud de EvaluHR (si aplica) |
| Titular de los datos | Candidato |

Esta clasificación es la práctica habitual en servicios SaaS de RR.HH. **No se cambia**; se audita para confirmar que las responsabilidades están claras.

## 4. Obligaciones del encargado (EvaluHR)

- Tratar datos solo según instrucciones del responsable (empresa cliente).
- No usar los datos para finalidad distinta.
- Implementar medidas de seguridad.
- Notificar brechas al responsable.
- Apoyar al responsable en responder ARCO.
- Devolver/eliminar datos al término del contrato.

## 5. Obligaciones del responsable (empresa cliente)

- Determinar finalidad.
- Obtener consentimiento del candidato.
- Publicar aviso de privacidad.
- Decidir contratación (humano).
- Responder ARCO (con apoyo de EvaluHR).
- Notificar al INAI en caso de brecha (si aplica).

## 6. Zonas de ambigüedad (a clarificar en contrato)

| Zona | Riesgo | Clarificación necesaria |
|---|---|---|
| Quien es entrevistador (¿empresa o EvaluHR?) | Responsabilidad de formación | Contrato debe especificar |
| Ownership de la evidencia | Si la empresa se va, ¿se llevan los datos? | Contrato debe especificar |
| Costo de ARCO | ¿EvaluHR cobra por facilitar ARCO? | Contrato debe especificar |
| Plazo de retención exacto | ¿2 años? ¿Otro? | Revisión legal |
| BFOQ | ¿Quién documenta y aprueba? | Contrato debe especificar (empresa) |

## 7. Conexión con gates

La clarificación de responsabilidades pasa LEGAL-G10 (Transparencia) + revisión legal del contrato. Sin responsabilidades claras, la entrevista no se activa.
