# A-06.4 — 04 · Datos que NO deben pedirse (PASO 4)

## 1. Regla

Ninguna pregunta de entrevista puede elicitar atributos protegidos sin justificación de BFOQ documentada y revisión legal. Si existe duda: **NO_PUBLICABLE** o **REQUIERE REVISIÓN LEGAL**.

## 2. Atributos protegidos (LFT Art 3 + LFPEPD + CONAPRED + Constitución Art 1)

| Atributo | Ejemplo de pregunta prohibida | Por qué |
|---|---|---|
| Edad | "¿Cuántos años tienes?" / "¿En qué año naciste?" | Atributo protegido; irrelevante para competencia |
| Fecha de nacimiento | "¿Cuál es tu fecha de nacimiento?" | Equivalente a edad; protegido |
| Sexo/género | "¿Eres hombre o mujer?" / "¿Cómo te identificas?" | Atributo protegido; irrelevante para competencia |
| Embarazo | "¿Estás embarazada?" / "¿Tienes planes de embarazo?" | Atributo protegido; discriminatorio (LFT Art 3; LFPEPD) |
| Maternidad/paternidad | "¿Tienes hijos?" / "¿Eres padre/madre?" | Situación familiar; protegido |
| Estado civil | "¿Estás casado/a?" / "¿Estás soltero/a?" | Atributo protegido; irrelevante |
| Religión | "¿Qué religión practicas?" / "¿Eres [religión]?" | Atributo protegido; irrelevante |
| Orientación sexual | "¿Cuál es tu orientación sexual?" | Atributo protegido; irrelevante |
| Identidad de género | "¿Cuál es tu identidad de género?" | Atributo protegido; irrelevante |
| Discapacidad | "¿Tienes alguna discapacidad?" (salvo BFOQ) | Atributo protegido; BFOQ restrictivo |
| Salud | "¿Tienes alguna enfermedad?" (salvo BFOQ) | Atributo protegido; BFOQ restrictivo |
| Enfermedades específicas | "¿Tienes VIH?" / "¿Estás en tratamiento psiquiátrico?" | Atributo protegido; discriminatorio |
| Información genética | "¿Tienes antecedentes genéticos de...?" | Atributo protegido; altamente sensible |
| Origen étnico | "¿Cuál es tu origen étnico?" / "¿Eres indígena?" | Atributo protegido; irrelevante |
| Nacionalidad (cuando no jurídicamente pertinente) | "¿De dónde eres?" (si no es requisito legal del puesto) | Atributo protegido salvo BFOQ (e.g. autorización de trabajo) |
| Opinión política | "¿Por quién votas?" / "¿Qué piensas de [político]?" | Atributo protegido; irrelevante |
| Afiliaciones | "¿Perteneces a un sindicato?" / "¿A qué asociación perteneces?" | Atributo protegido; puede ser sindical (LFT protege) |
| Situación familiar | "¿Con quién vives?" / "¿Tu pareja trabaja?" | Atributo protegido; irrelevante |
| Domicilio innecesario | "¿Dónde vives exactamente?" (salvo verificación logística justificada) | Privado; puede revelar origen/nivel socioeconómico |
| Apariencia física | "¿Cuánto pesas?" / "¿Cuál es tu talla?" (salvo BFOQ) | Atributo protegido; puede revelar salud |
| Idioma materno (si no es requisito del puesto) | "¿Cuál es tu idioma materno?" | Puede revelar origen; protegido salvo BFOQ |
| Antecedentes penales (sin justificación) | "¿Tienes antecedentes penales?" (salvo BFOQ) | Condicional; requiere justificación del puesto |

## 3. Excepciones legítimas (BFOQ)

Solo cuando exista **justificación jurídica y laboral** específica:

| Atributo | Excepción posible | Requisito |
|---|---|---|
| Edad | Puesto con restricción legal de edad mínima (e.g. LFT Art 22: 15 años mínimo) | Verificar requisito legal; no recoger más allá de lo necesario |
| Nacionalidad | Puesto que requiere autorización de trabajo específica | Verificar documento; no inferir por acento |
| Discapacidad | Puesto en refugio de mujeres (BFOQ género) o tareas que requieren capacidad física específica verificable | BFOQ restrictivo; revisión legal; no automatizable |
| Salud | Puesto con riesgo específico (e.g. manipulación de alimentos NOM-251 requiere carta salud) | Requisito legal; recoger como documento, no en entrevista |

**Regla**: BFOQ es excepcional, restrictivo, caso por caso, y REQUIERE REVISIÓN LEGAL. No se asume. No se automatiza. Ver `14-bfoq.md`.

## 4. Preguntas indirectas que elicitan atributos protegidos

| Pregunta indirecta | Atributo que elicita | Por qué prohibida |
|---|---|---|
| "¿En qué año te graduaste de la preparatoria?" | Edad | Permite calcular edad |
| "¿Cuántos años de experiencia tienes?" (seguido de "¿y antes?") | Edad | Puede inferir edad |
| "¿Cómo pasaste las vacaciones con tu familia?" | Situación familiar | Elicita estructura familiar |
| "¿Celebras Navidad?" | Religión | Elicita religión |
| "¿Tu pareja también trabaja en este sector?" | Estado civil/orientación | Elicita situación familiar |
| "¿De dónde es tu acento?" | Origen | Elicita origen |
| "¿Practicas algún deporte?" (si no es relevante) | Salud | Puede revelar capacidad física |

**Regla**: una pregunta indirecta que permita inferir un atributo protegido se trata como si preguntara directamente por ese atributo.

## 5. Manejo de revelación voluntaria

Si el candidato voluntariamente revela un atributo protegido (e.g. en una narración STAR menciona "mi esposa" o "mis hijos"):

1. **No registrar** como evidencia de competencia.
2. **No usar** para la decisión de contratación.
3. **No inferir** nada a partir de la revelación.
4. **Continuar** la entrevista sin profundizar en el atributo.
5. **Registrar** en notas solo lo relacionado a la conducta laboral (e.g. "el candidato describió coordinación con un familiar en una emergencia laboral" — sin identificar al familiar).

## 6. Regla: NO_PUBLICABLE

Una pregunta que pueda revelar un atributo protegido sin BFOQ = **NO_PUBLICABLE**. No se incluye en la guía de entrevista. No se usa en la sesión. Si un entrevistador la improvisa, se marca como **violación de guía** (auditable).

## 7. Conexión con gates

La prohibición de datos prohibidos pasa LEGAL-G4 (datos sensibles) + LEGAL-G5 (no discriminación). Sin esta prohibición documentada y aplicada, la entrevista no se activa.
